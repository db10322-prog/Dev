# 댓글 여론 요약 프롬프트 (T-6)

아래는 한 기사에 달린 댓글 원문 목록입니다. 다음을 요약하십시오. **댓글 원문을 그대로 인용하거나 작성자를 특정할 수 있는 표현(닉네임, 프로필 등)을 출력에 포함하지 마십시오.** 명예훼손·개인정보 리스크를 피하기 위해 항상 요약된 형태로만 답하십시오.

1. `forRatio` / `againstRatio`: 기사 주장에 대한 찬성/반대 비율 추정 (합 1.0, 애매하면 중립 비중으로 조정).
2. `topPoints`: 댓글에서 반복적으로 등장하는 주요 논점 3~5개, 각 1문장.
3. `alignmentWithArticle`: 기사 논조와 댓글 여론이 "일치" / "괴리" / "혼재" 중 어디에 해당하는지.

댓글이 비어 있으면 이 전체를 호출하지 않고 상위 파이프라인에서 opinion 섹션 자체를 생략합니다.
